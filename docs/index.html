Mermaid Viewer

A native macOS app for opening, previewing, and exporting Mermaid diagrams (.mmd files). Built with SwiftUI + WebKit.

⬜ macOS 14+ 🧜‍♀️ Mermaid 11 ⚡ SwiftUI 📦 Open Source
View on GitHub Installation

Features

🖼️

Live Preview

Renders Mermaid 11 diagrams in-app using WebKit. See changes instantly as you edit.

🎨

Light & Dark Themes

Toggle between Mermaid's default and dark themes with a single click.

📝

Source Editor

Split view to edit .mmd source alongside the rendered diagram.

🔍

Zoom & Pan

Toolbar zoom, ⌘+scroll from cursor, Shift+scroll to pan, box-draw zoom to area.

📤

Export

Convert diagrams to SVG, PNG, or PDF via mermaid-cli (mmdc).

📂

Default App

Registers as the system default handler for .mmd files. Double-click to open.

Zoom & Pan Controls

Multiple ways to navigate your diagrams

Action Input
Zoom inToolbar + button or ⌘+scroll up
Zoom outToolbar − button or ⌘+scroll down

Installation

# Clone and build
git clone https://github.com/james-see/mermaid-viewer.git
cd mermaid-viewer
xcodegen generate
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild \
  -project MermaidViewer.xcodeproj \
  -scheme MermaidViewer \
  -configuration Release build \
  CODE_SIGN_IDENTITY="-" CODE_SIGNING_REQUIRED=NO
cp -R ~/Library/Developer/Xcode/DerivedData/MermaidViewer-*/Build/Products/Release/MermaidViewer.app /Applications/

# Set as default for .mmd files
brew install duti
duti -s com.james-see.mermaidviewer .mmd all

# Enable export (optional)
npm install -g @mermaid-js/mermaid-cli
